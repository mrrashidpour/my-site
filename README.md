# MohammadReza Rashidpour — Personal Website

A bilingual personal website and professional portfolio built with HTML, Tailwind CSS v4, and Vanilla JavaScript.

## Features

- Persian and English languages
- RTL and LTR support
- Dark and Light themes
- Responsive design
- Custom SVG logo
- Social media profiles
- Tailwind CSS v4
- Local storage for theme and language preferences

## Tech Stack

- HTML5
- Tailwind CSS v4
- Vanilla JavaScript
- SVG

## Installation

Clone the repository:

```bash
git clone https://github.com/mrrashidpour/personal-website.git
cd personal-website
```

Install dependencies:

```bash
npm install
```

## Development

Run Tailwind CSS in watch mode:

```bash
npm run dev
```

Open `index.html` in your browser using a local development server.

## Production Build

Generate the optimized CSS:

```bash
npm run build
```

The generated stylesheet will be available at:

```text
assets/css/style.css
```
